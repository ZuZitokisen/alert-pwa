# アラート PWA 確認版

**即時通知 ＆ リマインド**を目指すアプリの静的確認版です。すべて架空のデータです。

目指す流れは、Dotsなどが新しい予定の発表を検知 → 根拠を確認 → HTMLカレンダーを早めに更新 → PWAへ通知 → 必要な予定をリマインドすることです。
Time Markerのカード・カレンダー・迅速共有の思想を引き継ぎ、確定前の可能性も追跡します。
即時・必達は保証せず、確度と出典を分けて扱う方針です。

## この確認版で試せること

- 架空のカード・月カレンダー・検索・確度の絞り込み
- 「発表を検知（サンプル）」による新着・時間変更・可能性から確定への変化
- 同一サンプルを繰り返した場合の通知候補の重複抑止
- 掲載消失を中止と区別し、取得失敗では前回情報を保持
- 更新前後と根拠の表示
- 端末内に保存するリマインド設定例
- PWAのmanifest・Service Worker・オフライン用アプリ本体

## 実装していないこと

**実データの監視・Dotsからの自動更新・Push通知・時刻指定通知・TTM同期は動いていません。**
通知候補とリマインドは画面で確認する設定例です。設定時刻になっても通知しません。
許可を要求したり、外部へ予定や購読情報を送信したりしません。
個人情報・実予定・認証情報を入力する機能はありません。

GitHub Pagesは静的ファイルを配信します。本番の差分監視・通知配信には別のバックエンドが必要です。
リマインドや既読の例は、このブラウザーのlocalStorageにのみ保存します。

## ファイル

- index.html / style.css / app.js: 画面と操作
- demo-data.js / demo-store.js: 架空の入力と端末内の差分比較
- manifest.webmanifest / sw.js / icon*: PWA設定
- prototype-source.zip: サーバー側差分検知のローカル試作ソースとテスト（公開用に私的参照を除外）

外部ライブラリー・外部フォント・分析タグは使っていません。アイコンはこの試作向けの生成図形です。
ライセンスはまだ指定していません。
