# アラート PWA 予定版 v0.7.1

**発表に気づく。予定を忘れない。** 確定の予定も「かも？」の予定も追いかける、即時通知＆リマインドを目指した静的PWAです。

[確認版を開く](https://zuzitokisen.github.io/alert-pwa/)

**2026年11月11日〜2027年3月31日を対象に、確認できた公表済み予定を収録します。非公式の情報集約です。自動監視・Push配信・予約通知は未接続です。本体カレンダーには共通予定の購読URLを提供します。**

## 試せること

- 月カレンダーを上、選択範囲のカードを下に表示。初期は当日、日付で日、左端の週ボタンで週、月見出しで月のカードに切り替えます。可能性の予定は点線枠と「かも？」表示。
- メニューは Schedule / Favorite / News。Newsに予定の変更履歴・アプリ更新情報・仕様をまとめています。
- 超ときめき♡宣伝部 / RE-GE / Straight Angeli の切替。共通機能とアーティスト固有設定を分離。
- カードの検索、日時・名前・種類・お気に入り優先の並べ替え、確度の絞り込み。
- 特典会・お話し会は画面表示と種類順で EVENT に統合。購読互換のため元データの BENEFIT 分類は保持します。
- お気に入りを端末内に保存。
- アーティスト別・種類別の共通カレンダー購読。全予定と内訳の重複選択を抑止。15個の固定公開URLから、日付のある272項目を配信。日付未定11項目は配信しません。
- 新着・変更の通知文面プレビュー、変更前後と根拠の確認。
- 朝時刻（既定8時）＋開始1時間前、または明示された締切前のリマインド候補。
- 公開データと前回の端末保存を比較する、新着・変更・重複抑止・掲載消失・取得失敗時の情報保持。
- 特典会の部別開催、受付開始・締切、応募期限を分けて表示。個別の出典URL・確認時刻・日時未定を表示。
- PWA manifest、Service Workerによるアプリ本体のオフライン保存。

リマインド候補は、過去の実装記録で確認できた時間規則のプレビューです。23:59締切の専用設定では23:00を候補にします。開始後の朝通知や過去時刻を省略し、同じ予定の同時刻候補をまとめます。現行の既存アプリとの完全一致は未検証です。

## 実機能とプレビューの違い

**通知許可を要求せず、実際のOS通知を発行しません。設定時刻になっても通知は届きません。** GitHub Pagesだけでは継続監視やサーバー側の通知予約はできません。実運用には情報取得・照合・保存・再試行・通知配信・予約管理を行うバックエンドが必要です。

本体カレンダーには、共通予定を継続して読む固定URLを提供します。「本体カレンダーに追加」からプリセットを選び、各購読リンクで端末の確認画面を開きます。リンクが開けない場合はURLをコピーして照会カレンダーに追加できます。読み取り専用で、反映間隔は端末側に依存します。iPhone実機での登録・更新反映は未検証です。

運用時は schedule-data-v2.json の確認済み情報を更新し、`node generate-subscription-feeds.mjs` と `node generate-subscription-feeds.mjs --check` を実行して、新旧の公開データと calendar-feeds/ 全体を同じコミットで公開します。UIDと改訂状態は保持され、同じ購読URLが更新されます。これは自動収集・即時更新の稼働を意味しません。手順と復旧は [SUBSCRIPTION.md](./SUBSCRIPTION.md) に記載しています。

お気に入り・リマインド設定例・既読等はこのブラウザーのlocalStorageに保存します。端末間同期はなく、ブラウザデータの消去・容量整理で失われる場合があります。一般ユーザーが予定を追加する画面はありません。

目指す流れは、公開情報の発表検知 → 出典・確度を確認 → HTMLカレンダー更新 → 新着・変更通知 → 必要な予定のリマインドです。完全な即時・必達は保証せず、可能性と確定、掲載消失と中止、取得失敗を区別します。

## デザイン

白・淡い色・丸みのあるカード、種類表示、月カレンダーと対象範囲のカードを基調にしています。Apple Human Interface Guidelinesのレイアウト・操作・通知の考え方を参考にした独自実装です。特定のApple Design Skillを導入したものではありません。Appleのロゴ、SF Symbols、写真、外部フォントは使用していません。

## ファイル

- `index.html` / `style.css` / `app.js`: UIと操作。
- `artist-config.js`: アーティスト名・公式情報源の設定。公式サイトは案内のみで監視未接続。
- `schedule-data-v2.json` / `schedule-store.js`: 公表済み予定の整理データと検証・端末内差分比較。
- `demo-data.js` / `demo-store.js`: 旧版の架空入力。現行画面では読み込みません。
- `feature-core.js`: 日時・絞り込み・ICS・通知文面・リマインド候補の共通処理。仕様は [FEATURE-CORE.md](./FEATURE-CORE.md)。
- `calendar-subscriptions.js` / `production-feed-core.cjs` / `generate-subscription-feeds.mjs` / `calendar-feeds/`: 公開購読UI、生成処理、永続改訂状態、配信データ。旧 `subscription-core.js` は架空データの回帰検証専用です。[SUBSCRIPTION.md](./SUBSCRIPTION.md)を参照。
- `manifest.webmanifest` / `sw.js` / `icon*`: PWA設定。
- `prototype-source.zip`: v0.1時点のサーバー差分検知のローカル試作とテスト。今回の画面の最新ソースではなく、稼働中のバックエンドでもありません。
- [CAPABILITIES.md](./CAPABILITIES.md): iOS PWAの6項目の可否・条件と一次資料。

外部ライブラリー、外部フォント、分析タグは使っていません。個人情報・個人の予定・認証情報を入力する機能はありません。公式サイトへのリンクを開くと、その外部サイトへ移動します。ライセンスは未指定です。

## 実予定データについて

本人側の公式発表を「確定」、放送局・主催者・コラボ先だけの情報を「かも？」として区別します。この確度は発表元の区別であり、開催の保証ではありません。ファン情報は含めていません。

開催・受付・応募締切は別の日時として扱います。深夜25時台は翌日に正規化し、月だけの発表・閉店時刻・終演後などを任意の日時に置き換えません。期間内に追加が見つからなかった月も、予定がないという意味ではありません。将来のレギュラー枠は個別日程の確認済み分と、本人公式の定例情報から作った個別回未確認の「かも？」候補を区別します。定例表記だけで各回の実施・継続を確定しません。

元の記事本文・画像・会員限定内容は保存・配信しません。必要な予定事実を短く整理し、利用前に原典の最新条件を確認できるようリンクを付けます。個別サイトの利用条件や権利処理を一般的に保証するものではありません。

データ取得は当サイトのJSONのみ。一般利用者のブラウザからアーティスト公式サイトを巡回しません。取得失敗や不正なデータで前回情報を消さず、取得できていない状態を画面に表示します。初回読込は基準状態なので大量の新着通知を作りません。画面外の通知や自動予約はありません。

収録データは283項目（超ときめき♡宣伝部197／RE-GE50／Straight Angeli36）。Straight Angeliのうち19項目は毎週金曜の定例情報から作った個別回未確認の「かも？」候補です。特典会の各部、開催、受付開始、締切を別項目として数えています。既存2組の情報確認は2026年11月11日18:29 JSTまで、Straight Angeliの初期16項目は11月12日13:25 JST、追加ラジオの出典確認は13:54 JST時点。11/13のラジオ1回は個別番組表との一致を確認済みで、以後3月末までの19回は休止・変更・継続未確認の候補として扱います。完全網羅ではなく、新しい発表や変更は今後の確認が必要です。

## 3組対応と旧版の互換性

新画面は schedule-data-v2.json と calendar-feeds/manifest-v2.json を読みます。旧画面向け schedule-data.json と manifest.json は2組の情報を維持します。旧10購読URL・UID・改訂番号とお気に入りのキーは変えません。端末内の予定履歴・既読は新しい保存領域へ一度移行し、旧画面の保存内容を書き換えません。

v0.7.1では312件の自動テストが通過。3組の実予定、旧版の購読・データ互換、端末内履歴/既読の移行、日付不明と番組枠の区別を検証しています。iPhone実機は未検証です。

日時の補助ラベル「かも？」は情報源を決めつけません。出典欄で本人公式と外部情報を区別します。
